Downloads

Every file in the current release, and the one command your package manager needs. Version 0.1.0.

Linux, any distribution

One self-extracting file carrying a prebuilt binary. It verifies its own checksum before it writes anything, and installs either for you alone or for every user on the machine.

Download

Arch and derivatives

Two AUR packages. odyssey-design-bin unpacks the released binary and installs in seconds. odyssey-design-git builds the current commit from source.

yay -S odyssey-design-bin

Windows

An MSI through winget, or a portable build through Scoop. Both read the same release artifacts.

winget install Fs1lyric.OdysseyDesign

macOS

A cask from the project tap, built for Apple silicon and Intel.

brew install --cask fs1lyric/odyssey/odyssey-design

Checksums

The Linux installer checks itself before it unpacks, so a truncated download fails loudly rather than half-installing. Verify any file yourself with sha256sum.

FilePlatformSizeSHA-256
Loading. If this does not change, the file list is on the releases page.

Nothing is code-signed yet. Windows SmartScreen and macOS Gatekeeper will both warn about an unidentified developer, and that warning is correct: verify the checksum above against the file you downloaded before you run it.
